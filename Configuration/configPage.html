Automatic detection

Safety net that re-checks the library on an interval and queues anything the recording watcher missed. You can still run the "Scan library for commercials (Comskip)" task by hand when this is off.
How often that scan runs. Changing this takes effect after a server restart or after resetting the task's triggers in Scheduled Tasks.
When Jellyfin asks this plugin for segments during its Media Segment Scan, queue detection for items that don't have results yet. Comskip only runs automatically on files under the recordings folder and scan paths; anywhere else (e.g. archives on a NAS), a video gets breaks from an .edl another program left beside it, or from a manual scan. Turn off to keep detection strictly on the watcher + backstop scan.

Live scanning (experimental)

Start a second, live-tuned Comskip process the moment a recording begins, instead of waiting until it finishes, so the post-recording scan is near-instant. Requires live_tv=1 and output_edl=1 in your comskip.ini (output_edl is already required either way). Doubles CPU load for the duration of every recording, and because the live process is stopped (not gracefully) once the recording settles, a break right at the very end of the recording can occasionally be missed. Leave off unless instant post-recording marks are worth the extra CPU.

Show / folder filter

Limit which recordings automatic detection runs on. Each line is matched against the series name, the file name, and every folder in the path. * and ? wildcards work; a line with no wildcard must match in full (case-insensitive). Manual runs of the scan task ignore these lists.
If non-empty, ONLY matching items are detected. Leave blank to allow everything.
Matching items are never auto-detected. Applied after the allow-list.

Channel filter

Limit which DVR channels automatic detection runs on. The channel is captured by polling Jellyfin every 20 seconds for whatever is currently recording (the only way to catch it — it's gone from Jellyfin once a recording finishes) and cached for 2 days. For anything recorded before this was turned on, or once that cache entry has aged out, it falls back to a by-name lookup against the recently-aired program guide, which works in a normal broadcast lineup but returns nothing for a show with no recent guide coverage. Either way, an unresolved channel is treated as failing BOTH lists below (never passes the allow-list, always matches the block-list) — a block-listed premium channel is never scanned just because its channel couldn't be determined days later. Skipped entirely when both lists below are empty. Each line is matched against the channel name and the channel number; */? wildcards work the same as the show/folder filter above.
If non-empty, ONLY recordings from a matching channel are detected. Leave blank to allow every channel.
Recordings from a matching channel are never auto-detected. Applied after the channel allow-list. Typical use: exclude commercial-free premium movie channels Comskip has nothing to find on, e.g. HBO East, Showtime, Cinemax.

Manual re-detect

Run (or force re-run) detection for one item by ID. Find the ID in the item's URL in Jellyfin web (the id= query parameter on its details page). A forced run ignores the show/channel filters and any existing result, and clears currently-published segments before it starts.
Wipes this item's published segments and stored record without queuing a new scan — unlike a forced run above, which clears and then immediately re-scans, bypassing the show/channel filters as a side effect. Use this to remove a result that shouldn't have been produced (e.g. a channel-cache entry that expired before a backstop scan ran).

Audio format trim

Some broadcast recordings open (and/or close) with a different audio channel layout than the movie itself — e.g. a network preview/bumper block in 2.0 stereo before a movie broadcast in 5.1. Because Jellyfin determines a file's audio channel count by probing from the start, that leading junk makes the whole recording read as 2.0 even though the movie is 5.1. This scans the primary audio stream across the whole file, finds the channel-format run that contains the recording's own midpoint (correctly surviving DVR pre-roll padding that starts mid-way through a differently-formatted previous program), and can cut whatever's outside that run. Unlike commercial-skip segments, this can rewrite the recording file — off by default.
Master switch. Off disables both the automatic pipeline below AND the "Fix opening/closing audio format" item-details menu entry / manual button below.
When on, runs as part of the normal post-recording pipeline (same trigger as Comskip), before commercial detection. When off, trimming only ever happens from an explicit per-item click — build confidence in the detector against your own channels first.
Keeps the untouched original for good, as a hidden file next to the recording (.<name>.original<ext>; Jellyfin doesn't list hidden files), so "Undo trim" can always put it back. Off: it's kept for the days below, then deleted.
When the box above is off: how long a trim can be undone (a mistaken or curious press) before its original is deleted. 0 deletes it as soon as the trimmed file is in place. Applies to every trim: program start and audio format.
The channel-format run at the recording's midpoint must cover at least this fraction of the total duration, or the file is left untouched as ambiguous. 0.7 = 70%.
Leading/trailing non-movie audio shorter than this is left alone — not worth a re-mux for a couple of seconds.
Subtracted from each measured cut point so a slightly imprecise boundary never clips real movie content. Trade-off: this much extra junk audio is left in place.

Program start

Where a recording's program really begins, past the promos a channel runs first, for channels the audio check can't help with (Starz is 5.1 or stereo throughout). Pause a recording in the web player or JDVR on the program's first frame, press ✂ Edit, then Starts here (this recording) (each action asks for a second press that says what it will do), or pause on the card the channel shows just before its programs (Starz's "The following is rated…") and press Remember card (all recordings): that recording only gets a skip marker (whatever the setting below), so you can check where it lands; later recordings then find their start by themselves, marked or trimmed per the setting. A recording's "…" menu also has Remove program start (for a marker) and Undo trim (when the original was kept). Item menus in JDVR also have Find program start.
A skip marker is a Preview segment from the start of the recording to the program: players offer "Skip preview". Trimming cuts it off with the same safe trim as the audio-format fix (keeping the original as a backup when that's on above), then re-runs commercial detection.
Also on channels the channel filter keeps from Comskip. Does nothing until a card has been remembered; each recording is looked at once.
0.70 by default. Starz rating cards scored 0.83–0.97 against other films' cards; the closest other frame 0.53.

Who can edit recordings

Program start (Starts here, Remember card, Find program start, Remove program start), trims and Undo trim, the audio format fix, and scanning for or removing commercials. Administrators always can. Anyone else sees no edit buttons in the web player, its item menus or JDVR, and the server refuses them.

Badges

Status badges the browser overlay and Wholphin draw on recordings: amber while scanning, green when commercials are marked, grey when none were found, red when a scan failed.
